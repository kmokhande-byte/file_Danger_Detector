# file_Danger_Detector
A simple JavaScript-based malware file detector that scans files for suspicious content and identifies potentially harmful or harmless files using beginner-friendly cybersecurity concepts.


Project Purpose

This project was created to practice:

JavaScript conditions
if...else
includes()
Basic cybersecurity concepts
User input using prompt()
